# 📈 Stock Portfolio Tracker

## 📌 Project Overview

This is a simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

The application allows users to:

* Enter stock names and quantities
* Calculate total investment value
* Save portfolio details to a text file

---

## 🚀 Features

* User-friendly console interface
* Predefined stock prices
* Calculates total portfolio value
* Saves output to `portfolio.txt`
* Input validation for better usability
